# ScoreEditor — Project Context for Claude Code

## Об проекте

Профессиональный нотный редактор для браузера. Разрабатывается музыкантом и композитором с многолетним опытом работы в Sibelius. Цель — создать удобный веб-редактор с профессиональной нотацией, где весь рабочий процесс сосредоточен в одной панели.

**Главная идея:** В Sibelius инструменты нотации разбросаны по разным местам. Здесь всё важное — в одной нижней панели, всегда под рукой.

---

## Стек

- **Framework:** Next.js 14 + TypeScript
- **Рендеринг нотации:** Verovio (WebAssembly) — рендерит MusicXML/MEI в SVG
- **Шрифт нотации:** Bravura (SMuFL) — встроен в Verovio
- **Аудио:** Tone.js
- **Дизайн:** Figma → React компоненты

---

## Архитектура

```
Данные (MusicXML) → Verovio → SVG → React UI
```

- Пользователь работает с интерфейсом
- Данные хранятся в MusicXML формате (совместимость с Sibelius)
- Verovio получает MusicXML и возвращает готовый SVG с правильной нотацией
- Весь spacing, расстояния между нотами, ключи, такты — Verovio считает сам
- React рисует только интерфейс вокруг

### Подключение Verovio

```javascript
import VerovioModule from 'verovio/wasm';
import { VerovioToolkit } from 'verovio/esm';

const vrv = new VerovioToolkit(await VerovioModule());
vrv.setOptions({
  font: 'Bravura',
  scale: 40,
  pageWidth: 2100,
  adjustPageHeight: true,
});

vrv.loadData(musicXmlString);
const svg = vrv.renderToSVG(1);
document.getElementById('score').innerHTML = svg;
```

## Формат данных

**Основной формат: MusicXML**
- Совместим с Sibelius, Finale, Dorico, MuseScore
- Импорт/экспорт .musicxml файлов
- Внутреннее хранение тоже в MusicXML

**Важно:** Sibelius экспортирует `.sib` — его нельзя парсить в браузере напрямую. Нужен экспорт из Sibelius как `.musicxml`.

## Нижняя панель — структура вкладок

Главная особенность редактора. Все инструменты нотации в одном месте.

### Вкладки:

**1. Common** — самое используемое
- Длительности: целая, половинная, четверть, восьмая, 16-я, 32-я
- Точка (пунктирная нота)
- Паузы: целая, половинная, четверть, восьмая, 16-я
- Альтерации: бемоль, бекар, диез, дубль-диез, дубль-бемоль

**2. More Notes** — расширенные длительности
- 64-я, 128-я
- Двойная точка
- Связанные ноты (tie)
- Глиссандо

**3. Articulation** — штрихи
- Акцент `>`
- Тенуто `—`
- Стаккато `.`
- Маркато `^`
- Стаккатиссимо
- Тенуто + стаккато
- Акцент + стаккато
- Портато

**4. Dynamics** — динамика
- `pp · p · mp · mf · f · ff · fff · ffff`
- `sfz · sf · fz · fp · rfz`
- Крещендо (hairpin)
- Диминуэндо (hairpin)

**5. Ornaments** — украшения
- Трель `tr`
- Мордент
- Обратный мордент
- Группетто
- Форшлаг (appoggiatura)
- Аккиаккатура

**6. Groups** — группировка нот
- Тюплеты: 3, 4, 5, 6, 7, 9
- Начало/конец лиги вручную
- Разрыв лиги
- Лига через паузу
- Штиль вверх / вниз / авто
- Tremolo: /, //, ///

**7. Repeats** — повторы и структура
- Сегно `%`
- Кода
- Da Capo
- Fine
- Вольта 1-я, 2-я
- Начало/конец репетиции

**8. Lines** — линии
- Лига (slur)
- 8va, 8vb, 15ma
- Педаль и снятие
- Trill line
- Crescendo/diminuendo линии

**9. Symbols** — прочее
- Фермата (обычная, короткая, длинная)
- Цезура
- Дыхание
- Rehearsal mark
- Pedal marks

**10. Clefs** — ключи (смена ключа)
- Скрипичный
- Басовый
- Альтовый
- Теноровый
- Перкуссия

**11. Time** — смена размера
- Цифры 0-9
- C (alla breve)
- ¢

## Требования от музыканта

Это профессиональный инструмент. Нотация должна быть правильной:

- **Ключ** — только в начале системы (строки), не на каждом такте
- **Расстояние между нотами** — пропорционально длительности (целая занимает больше места чем четверть)
- **Ширина тактов** — автоматически выравнивается по ширине системы
- **Альтерации** — учитывают тональность (не показывать диез если он уже в ключе)
- **Штили** — направление вверх/вниз по правилам (ноты ниже средней линии — штиль вверх)
- **Лиги и связки** — правильное разграничение слура и tie
- **Перенос на новую строку** — автоматический, с правильным расстоянием

Всё это Verovio делает автоматически — не нужно реализовывать вручную.

## Что НЕ делать

- Не писать свой рендерер нотации — это тысячи правил
- Не использовать равномерную сетку для размещения нот — это неправильно
- Не добавлять ключ на каждый такт — только начало системы
- Не использовать шрифты Sibelius (Opus, Helsinki) — они проприетарные
